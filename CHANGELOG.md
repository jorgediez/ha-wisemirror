# Changelog

## 1.0.0

First public release.

- Discovery of WiseMirror mirrors on the LAN (UDP broadcast) or manual setup by IP.
- Sensors: indoor temperature, indoor humidity, weather location, IP address.
- Controls: display/night brightness, night mode and its schedule, 12/24-hour clock, date order,
  key tone, temperature unit, two-day weather, weather source.
- `wisemirror.set_location` action; optional sync with Home Assistant's home location.
- Integration-wide poll interval, IP-change recovery by MAC address, diagnostics.
- English and Spanish translations.
